Konfigurasi Koneksi Google Spreadsheets & Drive

Masukkan URL Web App dari Google Apps Script agar website ini membaca dan menulis data langsung ke Google Sheets milik Dusun Ngrombeh.

Skrip Penghubung Google Sheets (Code.gs)

  1. Buat Google Spreadsheet baru bernama Database Dusun Ngrombeh.
  2. Klik menu Ekstensi > Apps Script, lalu tempel kode di bawah ini.
  3. Klik Terapkan (Deploy) > Deployment Baru > Aplikasi Web.
  4. Setel akses ke "Siapa saja (Anyone)", salin URL Web App-nya ke form di samping.
